# Campus Connect — Production Platform

> **A real-world smart complaint, emergency response, and campus facility management platform.**

---

## 🚀 Quick Start (1-Click)

Double click `start_campus_connect.bat` in the project root:
- **FastAPI Backend**: `http://localhost:8000` (Swagger docs: `http://localhost:8000/docs`)
- **Next.js Frontend**: `http://localhost:3000`

---

## 🔑 Authentication System

### 1. Student Login
- **Login Credentials**:
  - **Student ID or Email**: e.g., `STU101` or `student@campus.edu`
  - **Roll Number**: e.g., `2024CS01`, `BT22ECE042`, etc.
- **Student Sign Up**:
  - Full Name
  - Roll Number
  - Student ID / Campus Email
  - Phone Number
  - Hostel / Block & Room Number

### 2. Staff / Warden / Admin Login
- **Login Credentials**:
  - **Staff ID or Email**: e.g., `ADM001`, `WRD001`, `STF001`, or `staff@campus.edu`
  - **Password / Security PIN**: default is `admin`, `warden`, or `staff`
- **Staff Sign Up**:
  - Full Name, Staff ID, Role (Technician, Warden, Admin), Department, Phone Number

---

## 🏛️ Campus & Issue Customizer (Settings ⚙️)

Anyone can adapt Campus Connect to their exact university or college:
1. **Campus Name**: Editable anytime (e.g. "Apex University", "ABC Institute of Technology").
2. **Campus Buildings / Hostels**:
   - Add your own hostels, departments, workshops, labs, or dining halls.
   - Or when submitting a complaint, students can click **"+ Type other building/place"** to type ANY location!
3. **Custom Complaint Categories**:
   - Add new categories (e.g. "Laboratory Equipment", "Sports Ground", "Cafeteria").
4. **Wipe Test Data**:
   - Click **"Clear All Tickets"** in Settings to start with a completely clean slate for your institution!
